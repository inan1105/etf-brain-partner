# ETF 브레인 파트너 V1.01

국내외 ETF를 **종목코드 · 종목명 · 심볼 · 국내/해외 · 주요섹터 · 주요자산 · 참조지수** 조건으로
`AND`/`OR` 묶어 찾고, 고른 종목을 **기술적분석 계산기**와 **아임차트 스토커** 상담으로
자유로이 오갈 수 있게 하는 독립 실행형 웹앱입니다.

ETF는 이름이 길고 서로 비슷합니다 — `KODEX 미국나스닥100` / `TIGER 미국나스닥100` /
`RISE 미국나스닥100` / `ACE 미국나스닥100`. 그래서 이 앱은 **찾는 비용을 줄이는 일**을
조건검색만큼 중요하게 다룹니다(6장).

## 1. 빠르게 실행

```bash
npm install
npm run snapshot   # 데이터 준비 (키 없으면 동봉 시드로 부트스트랩)
npm run dev        # http://localhost:5173  (/api 도 함께 동작)
```

키 없이도 **조건검색 · 분류 · 랭킹 · 빠른찾기 · 기술적분석/스토커 연결**이 모두 동작합니다.
현재가·거래대금·순자산만 비어 있으며, 앱이 그 사실을 화면에 밝힙니다.

### 연결 점검

```bash
npm run check
```

각 원천이 지금 어떤 상태인지 한 번에 보여줍니다. 키 승인을 기다리는 동안
앱을 띄우지 않고도 "됐는지" 확인할 수 있습니다.

```
●  대기   KRX 정보데이터시스템        키는 유효 · API 이용 권한 없음 (활용신청 승인 대기)
          → data.krx.co.kr → 오픈API → 마이페이지 에서 "ETF 일별매매정보" 승인 확인
●  실패   공공데이터포털 (대체)        등록되지 않은 서비스키
●  정상   Yahoo Finance (해외)      SPY 764.29 USD
○  미설정 OpenAI (gpt-4o)          OPENAI_API_KEY 미설정 — AI 해설만 비활성
```

#### KRX 401 은 두 가지 뜻입니다

| 응답 | 의미 | 조치 |
|---|---|---|
| `Unauthorized Key` | 키 자체를 모름 | 키 값을 다시 확인 (공공데이터포털 키와 다름) |
| `Unauthorized API Call` | **키는 유효**, 해당 API 권한만 없음 | 서비스별 활용신청 승인 여부 확인 |

전자를 후자처럼 안내하면 멀쩡한 키를 다시 발급받게 되므로, `api/_lib/krx.js` 가
둘을 서로 다른 문구로 구분해 올립니다.

### 국내 원천 — KRX 정보데이터시스템

```
GET https://data-dbg.krx.co.kr/svc/apis/etp/etf_bydd_trd?basDd=YYYYMMDD
헤더: AUTH_KEY: <KRX 발급 인증키>
```

키 발급은 `data.krx.co.kr → 오픈API → 이용신청`. **공공데이터포털 키와는 별개의 키입니다.**

`api/_lib/domestic.js` 가 `KRX_AUTH_KEY` → `DATA_GO_KR_KEY` 순으로 시도하고,
두 원천을 같은 내부 스키마로 정규화하므로 호출측은 어느 쪽인지 몰라도 됩니다.

KRX 를 1순위로 둔 이유는 **순자산총액(`INVSTASST_NETASST_TOTAMT`)을 직접 주기** 때문입니다.
공공데이터포털은 이 값이 없어 `NAV × 상장좌수`로 추정해야 했고, 적합도의 '규모' 축이
그만큼 부정확했습니다.

> `data.krx.co.kr` 화면이 쓰는 내부 엔드포인트(`getJsonData.cmd`)는 쓰지 않습니다.
> 세션 쿠키를 넣어도 `LOGOUT` 으로 거부되고, 개편에 취약합니다.
> 진단은 응답 코드로 구분됩니다 — `401 Unauthorized Key`(경로 정상·키 문제),
> `404`(경로 없음). `api/_lib/krx.js` 가 이 둘을 다른 문구로 알려줍니다.
> 필드명이 바뀌어 매핑이 전부 실패하면 조용히 빈 목록이 되지 않고,
> 수신한 응답 필드 목록을 담은 `KRX_SCHEMA` 오류를 올립니다.

### 실시간 시세까지 붙이기

1. [공공데이터포털 — 금융위원회 ETF시세정보](https://www.data.go.kr/data/15094807/openapi.do) 활용신청


## 3. 조건검색 — AND/OR 2단 구조

무제한 중첩 대신 **패싯 내부 / 패싯 사이** 2단으로 묶습니다.
실제 질의는 대부분 이 구조로 표현되고, UI가 단순해집니다.

```
[테마] AI·인공지능  (또는|모두)  반도체
          ↕  AND | OR
[자산] 주식
          ↕  AND | OR
[지역] 미국
```

- **패싯 내부** — `또는`(하나라도 보유) / `모두`(전부 보유). 다중태그 패싯에서만 의미
- **패싯 사이** — `AND`(전부 충족) / `OR`(하나라도 충족)
- **검색어 · 연금 조건** — 항상 `AND` (검색창의 자연스러운 기대)

패싯: 국내/해외 · 상장시장 · 투자지역 · 주요자산 · 주요섹터 · 테마 · 전략구조 · 운용사

### 분류는 어디서 오는가

금융위 API는 종목코드·종목명·기초지수명·시세만 줍니다.
**섹터·테마·자산군·전략은 `shared/taxonomy.js`의 규칙으로 종목명과 기초지수명에서 추론**합니다.

```
KODEX 미국배당커버드콜액티브
  → 해외 · 주식 · [배당, 커버드콜] · [액티브, 커버드콜] · 연금가능
```

> **규칙 작성 시 함정** — 짧은 영문 약어는 반드시 단어경계(`\bAI\b`)를 씁니다.
> 경계 없이 `AI` 로 두면 `Direxion **Dai**ly` 가 AI 테마로, `AR` 은 `Be**ar** 3X` 가
> 메타버스로 잡힙니다. 또한 JS 문자열 안에서는 `\\b` 로 두 겹 써야 정규식 단어경계가 되고,
> 한 겹(`\b`)이면 백스페이스 문자가 되어 규칙이 조용히 죽습니다.

운용사 공식 분류와 다를 수 있으며, 앱 하단에 그 사실을 명시합니다.

## 4. 적합도 랭킹 (100점)

| 축 | 배점 | 기준 |
|---|---:|---|
| 조건 적합 | 40 | 선택한 값 중 실제 보유 비율 + 종목명 앞자리 일치 가산 |

## 5. SEO

**조건 조합마다 고유 URL**이 생기고, 그 URL이 검색결과에서 의미를 갖도록 설계했습니다.

```
/?q=반도체&themes=AI·인공지능,반도체&themes_m=or&exposure=해외&join=and&sort=fit
```

- `title` / `description` — 조건 문장 + 결과 건수 + 상위 종목명으로 동적 생성
- `canonical` / `og:*` / `twitter:*` — 조건 URL로 갱신
- **JSON-LD** — `WebApplication`(+ `SearchAction`), `ItemList`(상위 20), `FinancialProduct`(상세)
- **robots** — 결과 0건은 `noindex, follow` 로 자동 전환
- **sitemap** — FAQ 프리셋 + 테마/섹터/자산 단일축 + 대표 2축 조합 84개 URL

```bash
SITE_ORIGIN=https://your-domain.com npm run sitemap
```

## 6. 찾는 비용 줄이기

ETF는 이름이 길고 구분이 비슷해 "정확히 입력해서 찾기"가 사실상 불가능합니다.
그래서 네 가지 경로를 함께 둡니다.

### 빠른 찾기 — `Ctrl`+`K` 또는 `/`

- **초성 검색**: `ㅁㄱㄴㅅㄷ` → 미국나스닥100 (운용사 4곳이 한 화면에)
- **브랜드 분리 매칭**: `나스닥` 을 치면 KODEX·TIGER 가릴 것 없이 앞부분 일치로 잡힘
- 코드·심볼 완전일치 최우선, 동점이면 순자산 큰 종목 우선
- `↑` `↓` 이동, `Enter` 열기, 각 행에서 TA·상담으로 바로 이동

### 쉽게 찾기 — 브랜드 칩 분리

목록·드로어의 종목명은 `KODEX` 같은 운용사 접두어를 작은 칩으로 떼어냅니다.
구별되는 부분(`미국나스닥100`)이 맨 앞에 와서 같은 지수 상품을 눈으로 바로 비교할 수 있습니다.
`src/lib/search.js` 의 `groupByBenchmark` · `diffPoints` 는 같은 기초지수 종목 사이의
실제 차이(보수·규모·구조)만 뽑아내는 유틸입니다.

### 최근 · 관심

- **최근** — 열어본 종목을 시간순 자동 기록 (localStorage, 12건)
- **관심** — 카드·상세의 ★ 로 직접 고정. 두 서비스를 오간 뒤 돌아올 자리

### 우측 탭 독 (모바일·데스크톱 공통)

화면 오른쪽 가장자리에 세로 탭을 붙여 어디서든 한 번에 엽니다.

| 탭 | 내용 |
|---|---|
| 찾기 | 빠른 찾기 오버레이 |
| 키워드 | 테마·전략·자산을 건수순으로 — 눌러서 즉시 조건 적용 |
| 섹터 | 주요섹터 + 투자지역 |
| 수익률 | 1주·1개월·3개월·6개월·1년 상위 25종목 (`/api/returns`) |
| 관심 | 고정한 종목 |
| 최근 | 최근 본 종목 |

좁은 화면에서는 독이 얇아지고, 드로어는 86vw로 열리며 탭 레일이 옆에 남아 바로 전환됩니다.

## 7. 기술적분석 · 스토커 연결

> **현재 두 서비스 모두 URL 파라미터로 종목을 받지 않습니다.**
> `ta.iamchart.co.kr`는 자체 `api/identify`를 쓰고, `stockr.iamchart.co.kr`는 Vue SPA로
> 인바운드 쿼리를 처리하지 않습니다(`URLSearchParams` 사용처는 Sentry뿐).

그래서 **새 탭 열기 → 클립보드 복사 → 붙여넣기 안내** 3단계로 연결합니다.
팝업 차단을 피하려고 창 열기를 클립보드 복사보다 먼저 수행합니다.

계산기 단축 문법을 그대로 지원합니다.

| 입력 | 동작 |
|---|---|
| `069500` | 빠른 분석 |
| `!!069500` | 가격거래표 |
| `!!!069500` | 종합차트 |

검색창에 `!!!069500`처럼 접두어를 붙여 넣으면 결과를 거치지 않고 계산기로 바로 보냅니다.

**추후 두 서비스가 `?q=`를 받게 되면** `src/lib/bridge.js`의 `TARGETS[].url`만 바꾸면
붙여넣기 단계 없이 바로 이동합니다.

### 브레인 모티프

로고와 히어로 배경은 `src/components/BrainField.vue` 의 **뉴럴 필드**입니다.
노드와 시냅스가 느슨히 이어지다 오른쪽 위로 올라가는 형태 — 뇌의 연결망이면서
동시에 상승 추세선으로 읽힙니다. 좌표는 고정값이라 새로고침해도 같은 그림이 나옵니다
(매번 난수로 그리면 브랜드로 기억되지 않습니다).

배경은 텍스처지 그래픽이 아니어야 하므로, 본문 카피가 놓이는 왼쪽은 마스크로 비우고
오른쪽으로 갈수록 짙어지게 했습니다. 뷰박스는 히어로 비율(400×120)에 맞춰
`xMidYMid slice` 로 두었습니다 — 정사각 뷰박스를 늘리면 노드가 타원 덩어리가 됩니다.

## 10. 데이터 출처와 한계

| 항목 | 출처 | 성격 |
|---|---|---|
| 국내 ETF 시세·NAV·순자산·기초지수 | **KRX 정보데이터시스템 Open API** | 실시간(일별) |
| 국내 ETF (대체 경로) | 공공데이터포털 금융위 ETF시세정보 | 실시간(일별) |
| 기간별 수익률 | 위 API의 과거 기준일 종가 비교 | 파생 계산 |
| 해외 ETF 시세·거래량·52주 | **Yahoo Finance** (chart API) | 실시간 |
| 해외 ETF 기간수익률 | Yahoo 일봉에서 계산 | 파생 계산 |
| USD/KRW 환율 | Yahoo (`KRW=X`) | 실시간 |
| 해외 ETF 종목·보수 | 동봉 목록 (`shared/us-etfs.js`) | 고정 |
| 국내 총보수 | 큐레이션 (`shared/fees.js`) | 참고값 · 수동 갱신 |
| 섹터·테마·자산 분류 | 규칙 추론 (`shared/taxonomy.js`) | 추정치 |

**알려진 한계**

- Yahoo Finance 는 공식 API 가 아닙니다. 응답 구조가 바뀔 수 있어 종목 단위로 실패를 격리했고,
  실패해도 목록·분류·연결은 그대로 동작합니다.
- 거래대금은 국내가 원, 해외가 달러입니다. 화면에는 원래 통화로 표시하고,
  정렬·필터는 `valueKrw`(USD/KRW 환산)로 비교합니다. 포트폴리오 배분은 원화 기준이라
  국내 상장 종목만 사용합니다.
- 해외 ETF 의 순자산총액은 Yahoo chart API 가 주지 않아 `—` 입니다(적합도 규모 축은 중립 처리).
- 총보수는 대표 종목만 채워져 있습니다. 나머지는 `—`로 표시되며 랭킹에서 중립 처리됩니다.
- 기간별 수익률은 **가격 수익률**입니다. 분배금(배당)은 반영하지 않으므로
  배당·커버드콜 ETF의 실제 총수익률보다 낮게 나옵니다.
- KOFIA 전자공시 보강은 전송 계층만 검증됐고 서비스명이 비공개라 기본 비활성입니다.
  `KOFIA_ENRICH=1` 과 `KOFIA_SVC_NAME` 을 함께 설정해야 동작합니다.
  (종목 상세의 '펀드요약정보'는 이와 별개로 항상 동작합니다 — 13장 참고)
- 분류는 종목명 기반 추론이라 운용사 공식 분류와 다를 수 있습니다.

## 12. 자주 찾는 요청 · AI 해설

FAQ 진입점과 자유 질문을 **OpenAI GPT 모델**로 답합니다. (`POST /api/ask`)

```bash
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4o      # 모델을 바꿀 때 여기만 고칩니다
```

키가 없으면 **AI 해설만 비활성**되고 나머지 기능은 그대로 동작합니다.

### 환각을 막는 방식

- 질문과 함께 **현재 조건으로 걸러진 실제 종목 상위 40건**을 컨텍스트로 넘깁니다.
- 시스템 프롬프트가 그 목록 밖의 종목명·코드·수치를 만들지 못하게 막습니다.
- 근거가 없으면 지어내는 대신 "현재 조건에서는 확인되지 않습니다"라고 답하고
  어떤 조건을 바꾸면 되는지 제안하게 합니다.
- 답변 하단에 사용 모델과 근거 종목 수를 함께 표시합니다.
- 컨텍스트의 키 이름에 단위를 박아 넘깁니다(`총보수(연,%)`, `현재가(USD)`). 숫자만 넘기면
  모델이 "보수: 0.35" 처럼 단위 없이 인용해 0.35%인지 0.35원인지 알 수 없게 됩니다.

### 표현 규칙

아임차트 기술적분석 가이드라인과 같은 기조를 지킵니다.
매수·매도를 권유하지 않고, 미래 가격을 단정하지 않으며, 개인 맞춤 투자자문이 아님을 전제합니다.
출력은 ■ ㅇ - 불릿만 사용해 계산기·스토커 리포트와 형식을 맞췄습니다.

> 모델명은 코드에 박혀 있지 않습니다. 사용할 수 없는 모델명을 넣으면 `/api/ask` 가
> OpenAI 의 오류 메시지를 그대로 돌려주고 화면에 표시하므로 바로 진단됩니다.
> 신형 모델이 `max_tokens` 대신 `max_completion_tokens` 를 요구하는 경우도
> 자동으로 한 번 바꿔 재시도합니다.

### 상담용 화면 구분

질문·응답 영역은 상담 중에 한눈에 구분되도록 앱의 다른 정보와 다르게 표시합니다.
명조체(Noto Serif KR) · 질문은 옅은 베이지 바탕 · 응답은 줄마다 괘선이 그어진 바탕 · 이중 괘선 테두리.

## 13. 국내 ETF 펀드요약정보 (금융투자협회 전자공시)

종목 상세 시트에서 국내 ETF 는 [dis.kofia.or.kr](https://dis.kofia.or.kr) 의 '펀드요약정보'를
협회 화면과 같은 탭 구성으로 보여줍니다. (`GET /api/fund?name=…&code=…`)

| 탭 | 내용 | 협회 서비스 |
|---|---|---|
| 펀드기본정보 | 기준가·설정원본·순자산, 펀드 분류, 보수(유형평균 비교), 관련회사 | `COMFundUnityBasInfoSO` |
| 수익률 추이차트 | 최근 1년 누적 운용수익률 vs KOSPI, 기간별 수익률 표 | `COMFundUnityPrfRtSO` |
| 가격변동 추이 | 최근 1년 기준가격 그래프, 최근 15거래일 표 | `COMFundPriceModSO` |
| 자산구성내역 | 주식·채권·유동성·기타 비중과 세부 구성 | `COMFundAssetsCmpsDescSO` |
| 결산 및 상환 | 신탁회계기간별 기준가격·과표·설정원본·구분 | `COMFundSettleExSO` |

- ETF 종목코드·ISIN(KR7…)은 협회 펀드표준코드(KR5…/K55…)와 달라 **펀드명 검색으로 찾습니다**.
  공식명 앞부분이 종목명으로 끝나는 경우만 받고(앞은 운용사명), 표기가 다를 때는
  '브랜드 + 나머지'가 모두 들어간 후보가 하나뿐일 때만 받아 '명칭 확인 필요'로 표시합니다.
  못 찾으면 틀린 펀드를 보여주지 않고 협회 사이트 링크를 안내합니다.
- 협회는 한 번에 6개월치까지만 돌려줍니다. 1년 추이는 6개월 이내 구간으로 나눠 받고,
  누적 수익률은 구간 경계일을 기준으로 곱해 이어 붙입니다.
- '협회 원문 ↗' 은 협회 펀드요약정보 화면을 그대로 엽니다.
- 공개 API 가 아니므로 결과를 1시간 캐시하고 IP 당 호출 수를 제한합니다. 협회 화면이 개편되면
  서비스명·필드명이 바뀔 수 있으며, 그때는 해당 탭만 "받지 못했습니다"로 표시됩니다.
